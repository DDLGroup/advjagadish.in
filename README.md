## 🛠️ Build & GitHub Upload Instructions

The production build is already compiled inside the `dist/` directory!

### Option 1: Upload `dist` folder to GitHub Repo (GitHub Pages)
1. Initialize or push to your repository:
   ```bash
   git init
   git add dist
   git commit -m "Upload production dist build for advjagadish.in"
   ```
2. Or in GitHub Pages settings, choose the branch and set the folder to `/dist` (or deploy directly from a `gh-pages` branch).
3. If uploading via GitHub web interface, simply drag and drop the files from the `dist/` folder into your repository.

### Option 2: Rebuilding anytime
```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Generate fresh production build in /dist
npm run build
```
